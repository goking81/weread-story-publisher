# v0.1.8 QA 记录

本轮只使用合成阅读数据、临时本地服务和本地浏览器；没有读取任何用户的 API Key、真实阅读数据或真实分享链接。

## 已验证

- `npm test`：12 项通过。覆盖加密、撤销、明文拒绝、输入上限、限流、本机 Key 配置、数据驱动 3–7 页生成、异常年度数据、Node CLI 端到端流程、并发本地存储。
- `node test/assets-check.mjs`：用真实 Wrangler Assets 绑定验证发布页是 200、没有 `/index.html` 的 307 重定向、条件缓存不会返回空页、撤销后为 404。
- `node test/browser-check.mjs`：Chrome 320/390/430 宽度；验证长书名、7 页动态故事、旧加密格式的 3 页回退、二维码、署名转义、缺失/错误密钥提示、动效与无横向溢出。
- 干净临时目录执行 `npm ci --omit=dev`，再用 Node 18.20.8 完整运行 CLI 流程通过。
- `npm run worker:check`：Cloudflare Worker 与 Assets 绑定可构建；`npm audit --omit=dev`：0 个已知生产依赖漏洞。

## 本轮修复

- 真实 Assets 对 `/index.html` 的重定向曾让 `/s/<slug>` 无法打开；现在固定读取规范资源路径，并由真实绑定回归测试覆盖。
- 不再在空页面或链接切换时遗留试用原型/上一份故事；错误密钥与重新打开链接都会更新页面状态。
- 主书按有效时长排序；损坏的可选书籍、异常作者、越界阅读日、极小占比会被安全省略或拒绝，不会生成虚构结论。
- 发布文件保存失败时会尝试撤回刚刚上传的故事，避免留下没有撤销凭据的孤立链接。
- 本地 Key 配置页限制回环 Host、同源 JSON 请求和大小；发布及撤销不要求再次读取 API Key。
- 根域名不会展示任何示例/用户故事；公开卡片只保留已审核的标题、摘要和书封，完整报告保持密文。

## 尚不应声称

- 未用真实微信读书 Key 调用生产 API；字段兼容性仍需不同真实账号继续观察。
- 未自动化真机微信好友/朋友圈的卡片和播放测试；微信客户端最终表现以真机为准。
- v0.1.8 不含 HyperFrames MP4 导出。该能力需要单独实现及 Windows/macOS、FFmpeg、相册与朋友圈的交叉测试。
